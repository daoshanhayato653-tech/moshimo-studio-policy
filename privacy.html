Privacy Policy — Moshimo Studio

Last updated: 2026-10-05

Moshimo Studio ("the Application") is a personal, non-commercial tool operated by a single individual (contact: https://github.com/daoshanhayato653-tech/Moshimo Studio-policy/issues). It uploads short videos created by the operator to the operator's own YouTube channel. The Application is not offered to the public and has no other users.

Use of YouTube API Services

The Application uses YouTube API Services. By using the Application you agree to be bound by the YouTube Terms of Service. Information accessed through YouTube API Services is also subject to the Google Privacy Policy.

Information we access

  • The authenticated user's own channel ID and channel title (channels.list, mine=true), used only to confirm which channel videos are uploaded to.
  • Status of videos the Application itself uploaded (videos.list), used to confirm that scheduled publishing was applied.

The Application does not access other users' data, comments, subscribers, analytics, or any channel other than the operator's own.

Information we store

  • An OAuth refresh token and access token, stored only on the operator's own computer in a file readable solely by the operator's account (permission 0600). Tokens are never transmitted anywhere except to Google's OAuth endpoints.
  • The YouTube video IDs, titles and scheduled publish times of videos the Application uploaded, kept in a local database on the same computer for duplicate-upload prevention.

Stored data is refreshed on each run. Video records are retained only while needed to prevent duplicate uploads and are deleted on request (see below). No data is stored on any server.

Information we share

The Application does not share, sell, or transfer any data obtained through YouTube API Services to any third party. Video content is generated from text written by the operator; no YouTube API data is sent to content-generation services.

Cookies and tracking

The Application is a command-line tool. It does not use cookies, web beacons, analytics, or advertising identifiers, and does not place or read any information on users' devices or browsers.

Revoking access and deleting data

Access can be revoked at any time from the Google security settings page. Locally stored tokens and records can be deleted by deleting the Application's data directory. To request deletion or ask a question, open an issue at https://github.com/daoshanhayato653-tech/Moshimo Studio-policy/issues; requests are handled within 7 days.

Changes

Changes to this policy will be posted on this page with an updated date.
